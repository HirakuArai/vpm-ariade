# Increment – 会話だけで新規プロジェクト作成 & 日本語 UI

## ゴール

1. `create_project()` が `identifier=None` なら自動で `proj-YYYYMMDD-HHMMSS` を採番
2. チャットで「プロジェクト作成」と送ると Kai が概要を尋ね、DRAFT プロジェクトを作成
3. 作成後 Kai が「次は ACTIVE にしますか？」と聞き、`set_status("ACTIVE")` を呼べる
4. 既存フォームページはラベルを日本語化（識別子＝空欄可、概要、作成ボタン）
5. UI メッセージ・ボタン表記はすべて日本語

---

## 変更タスク

### A. `core/project_service.py`

* `identifier: Optional[str]` を許可
* `None` の場合 `_autogen_id()` で ID 生成

### B. `app.py`（チャットハンドラ）

1. トリガー判定: メッセージに「プロジェクト作成」が含まれる
2. Kai: 「プロジェクトの概要を一行で教えてください」
3. 返信を受けたら `create_project(None, overview, created_by=user)`
4. Kai: 「プロジェクト **{id}** を DRAFT で作成しました。次は ACTIVE にしますか？」
5. ユーザーが「はい」なら `set_status(id, "ACTIVE")`、Kai: 「ACTIVE に設定しました！」

### C. `core/project_service.py` に `set_status()`

```python
from datetime import datetime

def set_status(identifier: str, status: str):
    path = PROJECTS_DIR / f"{identifier}.json"
    data = json.loads(path.read_text())
    data["status"] = status
    data["updated_at"] = datetime.utcnow().isoformat()
    path.write_text(json.dumps(data, indent=2))
```

### D. `pages/01_create_project.py`

* `submitted  = st.form_submit_button("作成")`
* `st.set_page_config(initial_sidebar_state="collapsed")`
