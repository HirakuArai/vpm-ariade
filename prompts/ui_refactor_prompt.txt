with sidebar navigation.  Implement the following:

   pages/1_new_project.py
     - Q&A chat to generate charter.yaml (reuse scripts/gen_charter.py logic)
     - Save generated charter to data/charters/ and place its filename into st.session_state.

   pages/2_preview_charter.py
     - Load selected charter from session_state.
     - Show editable preview with st.data_editor, allow save.

     - Run analyze_charter() and generate_wbs() on the selected charter.

4. Each page should include:
   - st.page_config with appropriate title and icon.
   - Proper error handling if prerequisites are missing.
   - Navigation buttons (“Next”, “Back”) that update st.session_state["page"].

5. Update requirements.txt if new dependencies (e.g. plotly) are needed.
6. Add docs/ui_migration.md explaining how to run the new multipage app.
